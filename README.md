# Сервис обратной связи

## Назначение

Веб-приложение для сбора, обработки и управления отзывами и обращениями пользователей. Сервис позволяет пользователям оставлять сообщения с обратной связью по различным категориям, а администраторам — управлять этими сообщениями и давать ответы.

## Целевая аудитория

- Конечные пользователи: Клиенты компаний, посетители сайтов, пользователи, желающие оставить отзыв или обращение
- Администраторы: Менеджеры, сотрудники поддержки, ответственные за обработку обратной связи

## Предметная область

Сервис обратной связи относится к области управления клиентским опытом и предоставляет структурированный способ сбора и обработки отзывов. Основные процессы включают:
- Создание сообщений пользователями с указанием категории
- Классификация сообщений по категориям
- Обработка сообщений администраторами
- Предоставление ответов на сообщения
- Анализ и мониторинг обратной связи

## Основные сущности

- **Пользователь**: Лицо, использующее сервис. Может быть обычным пользователем или администратором. Имеет имя, email, роль.
- **Сообщение**: Отзыв или обращение, оставленное пользователем. Содержит текст, дату создания, статус обработки и привязку к категории.
- **Категория**: Тематическая группа для сообщений (например: "Общее", "Техническая поддержка", "Предложение", "Жалоба").
- **Ответ**: Ответ администратора на сообщение пользователя. Содержит текст, дату создания и привязку к сообщению.

## Основные функции

1. Регистрация и авторизация пользователей
2. Создание нового сообщения обратной связи
3. Просмотр списка всех сообщений пользователя
4. Просмотр статуса обработки сообщения
5. Получение ответа на свое сообщение
6. Администрирование категорий (создание, редактирование, удаление)
7. Обработка сообщений администраторами (изменение статуса)
8. Создание ответов на сообщения администраторами

## План развития

На следующих этапах планируется:

1. Разработка консольной программы с функциями для управления сообщениями, категориями и пользователями
2. Реализация основных сущностей в виде классов с использованием ООП
3. Создание Django-проекта и базовых веб-страниц
4. Подключение базы данных и создание моделей
5. Реализация полноценной работы с данными и административного интерфейса
6. Реализация регистрации, аутентификации и авторизации пользователей
7. Написание автоматизированных тестов
8. Разработка REST API, контейнеризация в Docker, настройка CI/CD
