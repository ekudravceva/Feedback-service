## 3. Индивидуальный проект

**Название проекта:** Сервис обратной связи

Консольное приложение для учета сообщений обратной связи от пользователей и управления ответами администратора на эти сообщения.

### Функции, реализованные на ПР2

Функциональность распределена по модулям и построена на функциях из ПР1, доработанных под работу с коллекциями:

- `users.py` — `add_user`, `find_user`, `can_create_message`, а также перенесенная из ПР1 функция `get_user_role_description`;
- `messages.py` — `add_message`, `find_messages`, `filter_messages_by_status`, `filter_messages_by_category`, `sort_messages_by_date`, `count_messages_by_field`, а также перенесенные из ПР1 функции `check_message_validity` и `get_message_status_text`;
- `responses.py` — `create_response`, `cancel_response`, `is_message_answered`, `get_responses_for_message`, генератор `iter_unanswered_messages`;
- `storage.py` — `load_json`, `save_json` (чтение и запись JSON-файлов через контекстный менеджер `with`, обработка отсутствия файла и некорректного JSON);
- `utils.py` — `input_int`, `input_nonempty_str`, `input_choice` (безопасный ввод данных с повтором запроса при ошибке).

Реализованы: добавление и поиск пользователей и сообщений; фильтрация сообщений по статусу и категории; сортировка сообщений по дате (с использованием lambda-функции в качестве ключа); создание и отмена ответов на сообщения с запретом повторного ответа; статистика по сообщениям (количество по статусам и категориям); отбор сообщений без ответа с помощью генератора.

### Структура модулей проекта

```
Feedback-service/
├── README.md
├── requirements.txt
├── .flake8
├── main.py        — точка запуска, меню и основной сценарий

├── responses.py    — работа с ответами на сообщения

    └── test_responses.py
```

### Формат хранения данных

Данные хранятся в каталоге `data/` в виде JSON-файлов со списками словарей. Пользователи при загрузке преобразуются в словарь `dict[int, dict]` по идентификатору, сообщения и ответы обрабатываются как список словарей `list[dict]`. Пример записи сообщения (`data/messages.json`):

```json
{
  "id": 1,
  "user_id": 1,
  "category": "Техническая поддержка",
  "text": "Не могу войти в личный кабинет, пишет ошибка 504",
  "status": "новая",
  "created_at": "2026-09-14 12:00"
}
```

- созданы автоматизированные тесты `pytest` (`tests/test_messages.py`, `tests/test_responses.py`), все 9 тестов проходят;
- обновлен файл `README.md` с описанием возможностей, структуры и формата данных проекта;
- результат зафиксирован в Git-репозитории.
